# R19-F5 — Financial outcome metrics

## Change

- Added bounded `wagering_transactions_total{source,status}` for HTTP, SQS, and reference-worker outcomes. Sources are fixed to `http`, `sqs`, and `reference`; statuses are fixed to `PROCESSED`, `REJECTED`, `PENDING_REFERENCE`, and `FAILED`. Unknown values are ignored. HTTP status labels are also restricted to known response codes plus `other`.
- Added per-source processing duration sum/count for SQS and reference attempts, while retaining the original HTTP duration counters and all retry, duplicate, conflict, redrive-candidate, outbox lag, and reconciliation metrics.
- Added a 15-second snapshot of unpublished outbox count and oldest age from PostgreSQL, and visible DLQ messages from the inbound queue's SQS redrive target. A failed poll retains last good values and logs the failure; DLQ visibility is the SQS approximate queue count, distinct from redrive candidates.
