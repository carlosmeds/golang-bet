# R19-F7 — Direct multiprocess concurrency evidence

## STATUS

Done. The system suite now exercises all three F-7 cases with real PostgreSQL, SQS, Keycloak, and separate application processes. No production files changed.

## CHANGES

- After the 80/80 balance race, resend both BETs through another process. Both return the stored `PROCESSED` or `REJECTED` result as an idempotent replay; balance, version, and ledger entry count stay fixed.
- Hold wallet A's PostgreSQL row lock, prove an A request is waiting in `pg_stat_activity`, and prove wallet B commits while A remains blocked. Release the lock and verify A then commits.
- Race an HTTP BET and its SQS equivalent while both are waiting on the same wallet row. The HTTP target consumes a separate test queue, so SQS is necessarily handled by another application process. Verify the completed inbox, one transaction, one BET ledger entry, unchanged replay balance, and SQS deletion.
- Use fresh FIFO queues for the race and crash/redelivery scenarios. All queues are created with unique names and registered for cleanup; app processes stop before the test-level queue cleanup.

In the first copy, removing `FOR UPDATE` from `LockWallet` made the held-wallet assertion fail after 30 seconds (`multiprocess_test.go:186`). In the second copy, bypassing the two pre-lock and post-lock idempotency checks made the 80/80 replay return 409 instead of 200 (`:136`) and prevented the cross-transport inbox completion assertion (`:254`). These failures show the new assertions reject the intended broken serialization and idempotency behavior.

## LIMIT

The cross-transport test proves overlap by observing two PostgreSQL lock waiters. It queues HTTP first, so it does not force the SQS request to win the wallet lock; the separately tracked F-10 inbox fallback gap remains with its owner. An exploratory subsequent SQS replay on the same local FIFO queue did not produce a completed inbox within 30 seconds, with no consumer processing log; fresh per-scenario queues made the required race and existing crash/redelivery test pass reliably.
